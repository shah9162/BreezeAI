# 🚀 BreezeAI Automation Framework

## 📌 Overview
This project is an end-to-end UI automation framework built for Breeze AI Use Cases using:

- Playwright
- Cucumber (BDD)
- TypeScript
- Allure Reporting

---

## 📂 Features Covered

- Filtering
- Search
- Navigation
- Deep Linking
- Detail Page Validation

---

## 🚀 Setup Instructions

1. Clone the repo
git clone https://github.com/shah9162/BreezeAI.git
cd BreezeAI

2. Install dependencies
npm install

3. Install Playwright browsers
npx playwright install

4. Install Java (required for Allure)

5. Run tests
npm run test

6. Generate report
npm run report
